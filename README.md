# Evermotion: Living Physics Universe

A physics-driven, offline-first sandbox game built with React, Vite, Tailwind CSS, and Web Audio API.

Created by **Kapil · SarlaYash Productions**.

---

## 🚀 Quick Start & Installation

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm or yarn

### 1. Clone or Download the repository
```bash
git clone https://github.com/sarlayash/EVERMOTION-Powered-By-Kapil---SarlaYash-Productions.git
cd EVERMOTION-Powered-By-Kapil---SarlaYash-Productions
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 4. Build for Production
```bash
npm run build
npm run preview
```

## 🎮 How to Play

- **Touch / Drag Mo**: Launch Mo across the skies, fling objects, or bounce on the terrain.
- **Deform Landscape**: Swipe along the ground to bend and warp rolling hills.
- **5 World Ages**:
  - **Age 1: Curious**: Tap clouds for birds, trees for bouncy fruits, drag birds to the sun to form rainbows.
  - **Age 2: Chaos**: Challenge modes (Juggle Mo in air for 30s, fling 10 objects, battle the Giant Chicken).
  - **Age 3: Reality**: Zero-gravity switch, Time Rewind (press and hold), ignite fire, spray water, and eclipse toggle.
  - **Age 4: Dream**: Enormous size rules, upside-down gravity, and giant hand interactions.
  - **Age 5: Creator**: Build castles, erupt volcanoes, launch rockets, or trigger the 500 Chickens button!
- **Mo Remembers**: Persistent memory saves ruins, volcanoes, and session snapshots into `localStorage`.
- **Procedural Audio**: 100% synthesized Web Audio effects and ambient reactive music with zero latency.
